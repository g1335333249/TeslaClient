## GitHub Actions 与版本

仓库当前已配置 `origin`（SSH 443），与旧验收文档“无远程仓库”不符。本轮按要求**没有推送**。[CI #1](https://github.com/g1335333249/TeslaClient/actions/runs/39908393714) 对先前提交 `02ca62c` 显示：iOS job 成功，backend job 在 `mvn -B verify` 失败，整次 workflow 失败。通过 GitHub 连接读取 job 日志：旧版 14 项集成测试中 7 项通过、2 项断言失败、5 项异常。异常主要是 MySQL `DATETIME` 在 JDBC Map 查询中返回 `LocalDateTime`，代码强制转成 `Timestamp`；另外充电计划 `ALL` 日程被正则错误拒绝，缺少 `X-Confirm-Delete` 被错误映射为 401。上述代码已修复并增加单元回归测试，但本轮 0.2.1 尚未在 MySQL 集成环境或线上 CI 复测，不宣称已通过。

当前版本：**0.2.1**。本轮修复 3 类线上集成缺陷，新增隔离迁移与单元回归测试，更新 Maven、iOS Version/Build、README 和 CHANGELOG。基线提交：`02ca62c`；本报告所在本地提交以 `git rev-parse HEAD` 为准。

已修复的代码缺陷：MySQL `DATETIME` 在 JDBC Map 查询中可能是 `LocalDateTime`，此前在遥测最新信号、行程汇总和令牌刷新中强转 `Timestamp`；充电计划 `ALL`/选定星期的正则含有错误的必需分组；删除确认头缺失时框架在进入业务校验前把请求错误映射成 401。修复分别使用统一 UTC 时间转换、正确的重复日正则和可选确认头后显式校验。当前仅单元回归验证通过，MySQL 集成回归待执行。
