# VoltMate 0.2.0 API

所有端点要求 `Authorization: Bearer <VoltMate session>`，按车辆访问关系校验。完整字段与错误码可在 `/swagger-ui/index.html` 查看。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/vehicles/{id}/capabilities?refresh=true` | 能力状态、原因、固件、遥测版本、钥匙状态 |
| GET/POST | `/api/v1/vehicles/{id}/charging/plans` | 已提交计划、创建 Tesla 计划 |
| DELETE | `/api/v1/vehicles/{id}/charging/plans/{planId}` | 删除已提交车辆计划 |
| GET | `/api/v1/vehicles/{id}/charging/sessions/{sessionId}/cost` | 单次费用及准确度 |
| PUT | `/api/v1/vehicles/{id}/charging/sessions/{sessionId}/cost` | `{ "amount": 12.34 }` 手填费用 |
| GET | `/api/v1/vehicles/{id}/charging/cost-summary?days=30` | 费用合计、日趋势与电价时段对比 |
| GET | `/api/v1/privacy/export?format=json\|csv` | JSON 或 CSV ZIP 导出 |
| DELETE | `/api/v1/privacy/vehicles/{id}/trips` | 删除行程与轨迹 |
| DELETE | `/api/v1/privacy/vehicles/{id}/charging` | 删除充电历史 |
| DELETE | `/api/v1/privacy/account` | 删除 VoltMate 账户数据 |
| GET | `/api/v1/auth/tesla/consent-management` | Tesla 官方授权撤销页面链接 |

删除请求还需 `X-Confirm-Delete: DELETE_MY_DATA`。删除仅针对 VoltMate 服务器保存的数据；共享车辆历史需要先解除其他用户访问。API 不返回 Tesla Token 或密钥。充电计划 `applyState` 为 `APPLIED` 或 `FAILED`，不能将失败记录展示成车辆已设置。费用 `accuracy` 为 `ACTUAL`、`ESTIMATED` 或 `UNAVAILABLE`。

服务端解除绑定会删除本地令牌并停止后续操作。Tesla 官方授权同意关系需用户在 Tesla 官网撤销；设置页面提供官方入口。
